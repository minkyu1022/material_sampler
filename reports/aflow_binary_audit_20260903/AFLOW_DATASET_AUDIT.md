# AFLOW dataset audit for composition-conditioned crystal generation

Date: 2026-09-03  
Measured API: AFLUX (`https://aflow.org/API/aflux/`)

## Executive result

AFLOW is substantially richer than Materials Project for *candidate structures at the same binary composition*, because LIB2/LIB3 are created by decorating many crystal prototypes with unary/binary/ternary chemistries. It is useful for broadening a CSP model's structural modes, but raw AFLOW entry frequency is **not** a physical equilibrium distribution and must not be used as a Boltzmann target.

## What is in AFLOW

- Official landing page currently reports about 3.93 million compounds and 817 million calculated properties.
- `ICSD`: calculations of experimentally reported structures, organized by Bravais lattice.
- `LIB1`, `LIB2`, `LIB3`: hypothetical unary, binary, and ternary entries generated by decorating structural prototypes.
- Current AFLOW Prototype Encyclopedia reports 2,127 standardized prototypes.
- Available fields include relaxed/unrelaxed geometry, fractional and Cartesian positions, species, composition, normalized stoichiometry, `natoms`, forces, stress, energies, formation enthalpy, space group, Pearson symbol, prototype, calculation settings, AUID/AURL, and downloadable relaxed files such as `CONTCAR.relax` and CIF.

## Measured binary statistics

Full metadata scan of all 351,136 AFLUX entries satisfying `nspecies(2)`:

- LIB2: 328,608 entries
- ICSD: 22,528 entries
- Unique `(element pair, normalized stoichiometry)`: 39,669

Raw entries per exact binary composition:

| statistic | count |
|---|---:|
| mean | 8.85 |
| median | 2 |
| p75 | 7 |
| p90 | 31 |
| p95 | 41 |
| p99 | 59 |
| maximum | 473 |

A proxy structural-family key `(input prototype, relaxed space group, relaxed Pearson symbol, natoms)` gives almost the same distribution (mean 8.81). Thus most entries in the scan are distinct decorated prototype candidates rather than simple repeated API rows. This proxy is not a rigorous geometry deduplication; final data construction should use AFLOW-XtalFinder or a StructureMatcher-like relaxed-geometry comparison.

## Comparison with Materials Project

Measured MP summary database (154,377 records):

| dataset | exact binary compositions | mean structures/composition | median | p90 | p95 | p99 |
|---|---:|---:|---:|---:|---:|---:|
| Materials Project | 11,539 | 1.80 | 1 | 3 | 4 | 11 |
| AFLOW binary | 39,669 | 8.85 | 2 | 31 | 41 | 59 |

The comparison is not perfectly like-for-like: MP material records are more consolidated, while AFLOW deliberately enumerates decorated prototypes. That difference is precisely why AFLOW provides more same-composition candidates, but it also creates selection bias.

## Suitability for the proposed Crystallite/JANUS work

### Good uses

1. Pretraining or supervised continuation of a composition-conditioned CSP generator.
2. Exposing the model to multiple lattice/prototype modes at the same composition.
3. Candidate initialization/seeding before MLIP relaxation.
4. Hard-negative or metastable-structure coverage when formation enthalpy is retained.

### Incorrect uses

1. Treating every AFLOW row as an equally likely thermodynamic sample.
2. Interpreting the number of prototype decorations as phase probability.
3. Treating relaxed DFT structures as finite-temperature samples.
4. Using mostly-zero relaxed forces as sufficient data for learning the surrounding energy landscape.
5. Combining AFLOW and MP energies without reconciling DFT functional, pseudopotential, Hubbard-U, magnetic state, and correction conventions.

AFLOW entries are predominantly relaxed 0 K calculation outcomes. For JANUS-style physical post-training, AFLOW can provide starting modes, but the target score/weight still needs a consistent oracle evaluated under one Hamiltonian. Re-evaluate every retained geometry with the selected MLIP rather than mixing AFLOW DFT energies directly with the MLIP target.

## Minimal recommended data pipeline

1. Query only desired 2–3 element chemical systems.
2. Keep relaxed structures and provenance (`auid`, `aurl`, `catalog`, DFT settings).
3. Convert to one primitive-cell convention; retain original structure separately.
4. Remove failed/unphysical geometries and partial-occupancy cases unsupported by the model.
5. Deduplicate by relaxed geometry, not only formula or prototype label.
6. Retain formation enthalpy for stratification, but re-score all structures with the same MLIP.
7. Split train/validation/test by reduced composition **and** structural family to prevent prototype leakage.
8. Balance compositions/prototypes; never train according to raw AFLOW frequency.
9. Start with `N<=20` for compatibility with MP20-pretrained Crystallite; quantify excluded coverage before increasing `nmax`.
10. Use JANUS post-training rollout/score/replay only after this structural pretraining/continuation dataset is defined.

## Licensing

AFLOW database documentation states that repository data are free for scientific, academic, and non-commercial purposes; other use is prohibited. This is more restrictive than the AFLOW software license (GPLv3) and Prototype Encyclopedia submodule license (Apache-2.0). Dataset licensing must therefore be checked before any commercial model/data release.
